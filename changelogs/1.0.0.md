### Added
- Container holograms: looking at a chest, barrel, furnace, shulker box or any other container floats its contents above it, with stack sizes and the container name, refreshed every second from the server; empty containers show nothing
- Modded machine support with no per-mod code: any block entity that is a vanilla container or exposes an item handler on any face is read, and handlers shared across faces are counted once
- Lodestone containers: blocks that keep their inventory behind Lodestone's own supplier instead of a block capability, such as Malum's Spirit Jar, are read like any other container
- Loot containers: unopened loot chests and loot minecarts stay hidden by default, so looking at one never rolls its loot; a server setting shows them and generates the loot for the viewer
- Entity containers: chest minecarts, hopper minecarts, chest boats and chested horses peek the same way
- Ender chests: the hologram shows the viewer's own ender chest, not another player's
- Blacklist, as a server config list of block ids and the block tag holoinventorymodern:holo_view_blacklist, for blocks that never report contents, with Not Enough Patterns' Arcane Lectern blacklisted by default
- Single slot rule: containers holding one slot stay hidden unless a server config list or the block tag holoinventorymodern:holo_view_whitelist names them
- /holoinventorymodern command for operators to add, remove and list blacklisted and whitelisted blocks in game
- Peek key and toggle key, with a trigger setting for always, while sneaking or while the peek key is held
- Client settings for background opacity, stack sizes, container name and its colour, entity peeking and hiding while sprinting
- Hologram position: /holoinventorymodern offset, open to every player, places the hologram in the middle of the block, at its top, above it, or above it and moved left or right, up or down and forward or back, and the choice is kept in the client config
- Hologram size: /holoinventorymodern size, open to every player, scales the hologram up to three times its default, and the choice is kept in the client config
- Hologram position overrides per block in the client config, for multiblocks and blocks that look larger than one block
- Server settings for the report range and the number of stacks reported
